大模型出大错的页，恰恰是人也读不出来的页。写算法判很难——实测成像指标 单指标 AUC 只有 0.69–0.76，把误伤率压到 0 时只抓得到 8% 的坏页； 但人扫一眼就知道。所以这里不让算法下结论，只让它排队： 最可疑的排在最前面，把你有限的目光用在刀刃上。 点一下缩略图 = 标为「不可读」，再点一下取消。进度存在你自己的浏览器里。 扫完点「导出」，把 JSON 贴进仓库的 unusable_pages.json。 拿不准就点开看大图（右键新窗口打开）。
